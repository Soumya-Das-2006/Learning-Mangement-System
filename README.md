# Learning Management System

This is a legacy PHP application organized into frontend pages, backend actions, shared views, configuration, database migrations, and storage directories. Root-level compatibility symlinks preserve the existing include paths and URLs during migration.

See [docs/project-structure.md](docs/project-structure.md) for the proposed folder layout, file placement map, and migration sequence.

The live source files are organized under `src/`; existing URLs remain available through compatibility symlinks.
